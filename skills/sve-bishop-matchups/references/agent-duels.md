# 双座位实战中的选择

复习时先遮住终局，从对应回合的本方可见信息选一项。再比较执牌者亲自记录的实战理由、原始录像和赛后复盘。每个三职业循环共用一套主教。

- 第 1 场对破坏巫师，主教负。T9 输入 62 前的实战考虑为「进化灾藤，墓场的炎术可进EX本回合零费，仍剩2PP可打歪曲的进步。优先压低三名敌方从者的下一轮攻击；后续目标和每回合交本席公平预设。」。[原局及两席赛后复盘](https://github.com/WhiteLeafWhite/sve-exp/blob/main/batches/10-agent-duels/cQZr8Z/lessons/01.md)
- 第 2 场对侮蔑龙，主教负。T9 输入 50 前的实战考虑为「5/5圣士郎攻击横置3/1，预计剩5/2，龙族原有7点场攻归零。手里保留忒弥斯和席翁处理新一轮，此后交本席公平预设。」。[原局及两席赛后复盘](https://github.com/WhiteLeafWhite/sve-exp/blob/main/batches/10-agent-duels/zQrwne/lessons/01.md)
- 第 3 场对财宝皇室，主教胜。T9 输入 62 前的实战考虑为「我只剩1血，对方已有3、7、4、2攻四名从者。五费忒弥斯同时清场，白牙仍能在回合末回复。单个炎术或歪曲都留有足量攻击；下一回合的白牙召唤与后续交本席公平预设。」。[原局及两席赛后复盘](https://github.com/WhiteLeafWhite/sve-exp/blob/main/batches/10-agent-duels/t7B32v/lessons/01.md)
- 第 4 场对破坏巫师，主教负。T8 输入 47 前的实战考虑为「我16血、空从者，对方有2、4、2攻和公开黑色创造物。四费莉迪耶尔立即回4、给4/4守护并找承担者，既覆盖本轮交换也补下轮回复。后续由本席公平预设接手。」。[原局及两席赛后复盘](https://github.com/WhiteLeafWhite/sve-exp/blob/main/batches/10-agent-duels/cQZr8Z/lessons/02.md)
- 第 5 场对侮蔑龙，主教负。T8 输入 34 前的实战考虑为「手中没有可留1费使用的Quick，支付1PP普通进化、保住两点EP。第五个场位留给耶菈的祈祷。」。[原局及两席赛后复盘](https://github.com/WhiteLeafWhite/sve-exp/blob/main/batches/10-agent-duels/zQrwne/lessons/02.md)
