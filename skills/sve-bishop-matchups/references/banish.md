# 给信仰的一击留多少 PP

信仰的一击需要 3 PP。对侮蔑龙，发现已经进化的嘉鲁蜜儿时，可在自己的主阶段先消灭她。等对方宣告攻击才行动，对方可能已经在主阶段完成数次自伤。对刚上场便结算伤害的从者，还要单算其入场曲。每次交回合都要说出留下 3 PP 预期在哪个合法窗口干预。

侮蔑龙五局为 2 胜 3 负，3 局取入手牌，3 局实际使用。第 3 局选择侮蔑的团结者，主教负；第 4 局选择侮蔑的团结者，主教负；第 5 局选择侮蔑绝杰·嘉鲁蜜儿，主教负。 [逐局对照](https://github.com/WhiteLeafWhite/sve-exp/blob/main/batches/09d-bp20-banish/index.md)
