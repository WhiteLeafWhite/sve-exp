# 用手上的透京耶菈牌表选择打法

封存录像里共有九份透京耶菈主教。先核对主战者、主牌和进化牌，再套用对应的起手与终结判断。三种对手的顺序在本页统一为巫师、龙、皇室。每行都附有能离线导入的原牌表。

| 实战版本 | 实际变化 | 这个版本要多算的一步 |
|---|---|---|
| [首轮 v1](../assets/v1.json) | 万裁 3、炎术 3，主牌没有忒弥斯。 | 交回合前数已有的单解与守护。将万裁和分身带到下回合是终结路线。头三场对龙 2 胜 1 负。[首轮索引](https://github.com/WhiteLeafWhite/sve-exp/blob/6556d454e7baa65f7c18f233511868ab50700cb4/batches/01-zQrwne/games.md) |
| [首轮 v2](../assets/v2.json) | v1 的万裁、炎术各减 1，加入两张忒弥斯。 | 清场或弃牌前先算单解守护后的旧场攻击。第 5 局 T23 对方只有一个 1 防守护、9 血，一张炎术能打开两个 5 攻的攻击路线。实战 T29 胜，分支 T23 胜。[同盘重演](https://github.com/WhiteLeafWhite/sve-exp/blob/6556d454e7baa65f7c18f233511868ab50700cb4/batches/01-zQrwne/case-05-t23.json) |
| [A · 席翁玛文](bishop-final.json) | 主牌席翁、玛文各 2，进化玛文 2，忒弥斯 1。 | 席翁能挺过忒弥斯，先让会被清掉的己方随从行动。用席翁和水银分别减伤时，每段重算。第二至七批的 34/60 使用这份牌。[当时的三组成绩](results.md) |
| [B · 白牙萝蕾娜](bp20-150-final.json) | A 表加入白牙、萝蕾娜各 2，进化区萝蕾娜 2、玛文 2、灾藤 1。 | 白牙回复在己方结束阶段，萝蕾娜入场可立即回 4。按要不要在攻击前靠回复解场来排顺序。第二次玛文进化会连己方其他随从一起清掉。[基础卡位](bp20-deck.md) |
| [D · 神弓](../assets/D-lyrial.json) | B 表用两张神弓座天使换一张坚定不移的祈祷和一张莉迪耶尔。 | 神弓在场时主战者免能力伤害。横置起动前先数对方能否靠战斗移走神弓，以及本来仍会打到主战者的攻击。对龙同五个牌序 B 胜 4、D 胜 0。[配对记录](lyrial.md) |
| [E · 信仰的一击](../assets/E-banish.json) | B 表的同两个主牌位置改放两张信仰的一击。 | 留 3 PP 给 Quick 和在己方主阶段先消灭目标各算一次。对手如能在首攻前用能力收尾，留到宣攻窗口就太迟。对龙同五个牌序 B 胜 4、E 胜 2。[实际目标](banish.md) |
| [F · 双灾藤](bp20-recommended.json) | 与 B 主牌相同，进化区改为灾藤 2、玛文 1。 | 一张炎术能否打两次，取决于灾藤进化时炎术是否已在墓场，并有合法目标。出第一张玛文时也要算本局剩余清场次数。F 是下一阶段复用的主教基准。[进化位取舍](second-saito.md) |
| [S · 圣启梦羊](../assets/S-sheep.json) | 在 F 的主牌用两张梦羊换一张坚定不移的祈祷和一张莉迪耶尔。 | 梦羊在对手主阶段开始时给一次伤害防止。对手若能先交小额伤害，预期挡下的数值随之改变。每职业只完成 10 对。[实际触发](sacred-sheep.md) |
| [K · 天曜战骑](../assets/K-knight.json) | F 各减一张席翁和莉迪耶尔，加入两张天曜战骑。 | 五费战骑本身有疾驰、守护。已在场至少两个护符才额外加 2 攻并回 2。比较马上打 3 或 5，与少一张席翁的后续代价。每职业完成 25 对。[配对结果](heavenly-knight.md) |
