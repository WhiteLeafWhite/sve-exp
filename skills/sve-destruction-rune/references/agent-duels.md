# 双座位实战中的选择

复习时先遮住终局，从对应回合的本方可见信息选一项。再比较执牌者亲自记录的实战理由、原始录像和赛后复盘。每个三职业循环共用一套主教。

- 第 1 场对主教，破坏巫师胜。T8 输入 55 前的实战考虑为「独唱付两张偶像，打两次二点，主教下回合不能拿圣士郎作四攻起点。」。[原局及两席赛后复盘](https://github.com/WhiteLeafWhite/sve-exp/blob/main/batches/10-agent-duels/cQZr8Z/lessons/01.md)
- 第 4 场对主教，破坏巫师胜。T7 输入 39 前的实战考虑为「破坏绝杰在场后打出愉悦，回 1 PP 再抽一张，保留狂信者与白黑章等主教下随从。两名旧随从可对无守护主战者打四加二。」。[原局及两席赛后复盘](https://github.com/WhiteLeafWhite/sve-exp/blob/main/batches/10-agent-duels/cQZr8Z/lessons/02.md)
- 第 7 场对主教，破坏巫师负。T8 输入 50 前的实战考虑为「现在献荒野给祈祷者，剩一体的五攻圣士郎值这次二伤，三颗 EP 都留着。」。[原局及两席赛后复盘](https://github.com/WhiteLeafWhite/sve-exp/blob/main/batches/10-agent-duels/cQZr8Z/lessons/03.md)
- 第 10 场对主教，破坏巫师负。T7 输入 48 前的实战考虑为「用余下的一费进化，从可见的四张里选后续最能落地的两张偶像。」。[原局及两席赛后复盘](https://github.com/WhiteLeafWhite/sve-exp/blob/main/batches/10-agent-duels/cQZr8Z/lessons/04.md)
- 第 13 场对主教，破坏巫师胜。T8 输入 43 前的实战考虑为「用 EP 进化阿克西雅，打算献黑章找四费破坏绝杰，黑章遗言打主教 1、换出白章。之后两个祈祷者还可以各献一次护符。」。[原局及两席赛后复盘](https://github.com/WhiteLeafWhite/sve-exp/blob/main/batches/10-agent-duels/cQZr8Z/lessons/05.md)
- 第 16 场对主教，破坏巫师胜。T7 输入 40 前的实战考虑为「场上敌方随从已清。选祈祷者起动向主教打二，献黑章还会再打一点；直接用黑章自己的能力要横三张偶像且只给一点。」。[原局及两席赛后复盘](https://github.com/WhiteLeafWhite/sve-exp/blob/main/batches/10-agent-duels/cQZr8Z/lessons/06.md)
- 第 19 场对主教，破坏巫师负。T12 输入 98 前的实战考虑为「现在才出零费独唱，新显现、白章、暗黑创造物都未攻击，三张横置对女王一次打6。」。[原局及两席赛后复盘](https://github.com/WhiteLeafWhite/sve-exp/blob/main/batches/10-agent-duels/cQZr8Z/lessons/07.md)
