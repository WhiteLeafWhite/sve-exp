# 双座位实战中的选择

复习时先遮住终局，从对应回合的本方可见信息选一项。再比较执牌者亲自记录的实战理由、原始录像和赛后复盘。每个三职业循环共用一套主教。

- 第 2 场对主教，侮蔑龙胜。T8 输入 40 前的实战考虑为「一费给侮蔑之国看两张，并保留护符。对面已空场，嘲笑留作点自己；五费回合可先用一个自伤令旧嘉鲁蜜儿免费进化，另一个留到进化后。」。[原局及两席赛后复盘](https://github.com/WhiteLeafWhite/sve-exp/blob/main/batches/10-agent-duels/zQrwne/lessons/01.md)
- 第 5 场对主教，侮蔑龙胜。T9 输入 67 前的实战考虑为「用本已一体的五攻嘉鲁蜜儿交换最后的 5/4 圣士郎。四个敌方从者都被移除，己方回到 12 血，还留三体守护以及崇拜者，保住下回合。」。[原局及两席赛后复盘](https://github.com/WhiteLeafWhite/sve-exp/blob/main/batches/10-agent-duels/zQrwne/lessons/02.md)
- 第 8 场对主教，侮蔑龙胜。T8 输入 40 前的实战考虑为「再下狂信者：全场一伤后天冥剩三体，崇拜者的触发负责补三。保住 4/1、2/1 两个随从及两颗 EP。」。[原局及两席赛后复盘](https://github.com/WhiteLeafWhite/sve-exp/blob/main/batches/10-agent-duels/zQrwne/lessons/03.md)
