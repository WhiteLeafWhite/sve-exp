# 双座位实战中的选择

复习时先遮住终局，从对应回合的本方可见信息选一项。再比较执牌者亲自记录的实战理由、原始录像和赛后复盘。每个三职业循环共用一套主教。

- 第 3 场对主教，财宝皇室负。T8 输入 58 前的实战考虑为「副船长再打三，将主教从四血压到一血。五旗五点、炮手四点、两次攻击七加三，合计十九。」。[原局及两席赛后复盘](https://github.com/WhiteLeafWhite/sve-exp/blob/main/batches/10-agent-duels/t7B32v/lessons/01.md)
- 第 6 场对主教，财宝皇室胜。T7 输入 37 前的实战考虑为「黄金短剑打直立圣士郎二伤，另外两名旧随从的攻击留给主战者。」。[原局及两席赛后复盘](https://github.com/WhiteLeafWhite/sve-exp/blob/main/batches/10-agent-duels/t7B32v/lessons/02.md)
- 第 9 场对主教，财宝皇室胜。T8 输入 57 前的实战考虑为「第二面免费旗给炮手或芭芭萝丝都是八狱盗贼。分开加攻击，若主教解芭芭萝丝，炮手还能有三攻。」。[原局及两席赛后复盘](https://github.com/WhiteLeafWhite/sve-exp/blob/main/batches/10-agent-duels/t7B32v/lessons/03.md)
