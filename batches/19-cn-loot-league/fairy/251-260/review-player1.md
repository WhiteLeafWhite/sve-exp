# 选手 1 复盘

本席编写的复盘规则根据已结束局生成。

财宝皇 3 胜 7 负 0 和。先攻 1/5，后攻 2/5。本席直接输入 0 次，自编策略输入 129 次，公平搜索补位 266 次。

前八个总回合内，6/10 局有一轮对手行动令本方少至少 4 血。

败局中可接手 g0254 T7 输入 35。该轮体力从 17 降到 8，可见动作包括打出 妖精剑师·阿玛兹 妖精 新→ex。

选回费的 8 个己方回合里，有 3 回合同回合买进炮手。示例 g0260 T8 输入 54 选择回费，输入 55 下炮手。

对手回合起点仍留常见 Quick 的费用时，观察到 1 轮先攻后旗，例如 g0256 T12 输入 112 攻击，输入 118 才打旗。
