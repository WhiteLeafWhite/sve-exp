# BP20 财宝皇对三套困难 Bot

我方持 **t7B32v 原表**，三张 BP05-018。对手按原始 SVE Helper 牌表固定为侮蔑龙 zQrwne、破坏法 cQZr8Z、财宝皇 t7B32v。每个对局 100 局，50 先攻、50 后攻，每组目标至少 65 胜。正式种子由对手代码和局号唯一确定，单数我方先攻。调整打法从下一局生效，已经完成的正式场保留原记录。

- [实时战绩和每十局复盘](index.md)
- [本方原表](decks/t7B32v.json) · [侮蔑龙原表](../06-zQrwne/opponent.json) · [破坏法原表](../05-cQZr8Z/opponent.json) · [镜像原表](../07-t7B32v/opponent.json)
- [测试约定和牌表校验值](protocol.json) · [本轮打法版本](pilots.md)

使用 SVE NEXT 0.4.3 标准构筑与自动规则。双方按约定开放原表中的超限或禁用卡，关闭赛制禁限过滤。困难席使用 GUI 对应 `hard-next` 满强度（effort 1），按引擎定义读取隐藏信息。财宝皇的策略由本次会话编写，逐步使用合法行动及本方能看见的牌，结合原生引擎对未知牌进行采样和向前搜索。录像同时保留双方复盘所需信息，赛后才读取完整状态核对终局。

正式局以胜负与原生录像为准。可以在 SVE NEXT 的 Watch replays 打开每局 JSON。逐局日志用总回合号 T，输入号为原生录像 `inputs` 的零起点下标。练习档采用独立牌序，记录在 [校准](calibration.md)，胜负不并入 300 局。

## 复现

在上述版本的模拟器目录安装其锁定依赖后，用 Node 运行此目录的 `prepare.mjs`。运行 `block.mjs dragon 1 10 1` 可复现首个龙组的十局，末参填写相应复盘所记的打法版本。运行 `report.mjs dragon 1 10` 可验证同一批原生录像并生成逐局日志。三组键名为 `dragon`、`rune`、`mirror`。
