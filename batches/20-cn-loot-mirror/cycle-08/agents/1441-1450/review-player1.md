# 选手 1 复盘

选手编写的复盘规则根据已结束局生成。

财宝皇本席 7 胜 3 负 0 和，先攻 3/5，后攻 4/5。手选 0 次，自编策略命中 136 次，搜索补位 280 次。

前八个总回合，4/10 局在对手某一回合净掉至少 4 血。

本方回合起点对手仍有至少 1 PP，且该轮既打旗又攻击的窗口共有 1 次，其中 0 次先攻后旗。示例 m1446 T18 输入 165 打旗，输入 174 攻击。

选芭芭萝丝回费的 6 回合里，2 回合把买炮手排在下一旗之前。示例 m1444 T8 输入 52 回费，输入 53 买炮手。

从行动记录能确认本方拆掉炮手或芭芭萝丝 19 次。敌回合用精炼命中这两种发动机共 2 次。示例 m1443 T10 输入 63，回合起点留 2 PP。
