# 选手 1 复盘

选手编写的复盘规则根据已结束局生成。

财宝皇本席 9 胜 1 负 0 和，先攻 4/5，后攻 5/5。手选 0 次，自编策略命中 160 次，搜索补位 315 次。

前八个总回合，6/10 局在对手某一回合净掉至少 4 血。

本方回合起点对手仍有至少 1 PP，且该轮既打旗又攻击的窗口共有 1 次，其中 0 次先攻后旗。示例 m1203 T11 输入 80 打旗，输入 83 攻击。

选芭芭萝丝回费的 9 回合里，3 回合把买炮手排在下一旗之前。示例 m1205 T9 输入 56 回费，输入 57 买炮手。

从行动记录能确认本方拆掉炮手或芭芭萝丝 16 次。敌回合用精炼命中这两种发动机共 0 次。
