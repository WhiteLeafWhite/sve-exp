# 选手 1 复盘

选手编写的复盘规则根据已结束局生成。

财宝皇本席 5 胜 5 负 0 和，先攻 3/5，后攻 2/5。手选 0 次，自编策略命中 110 次，搜索补位 273 次。

前八个总回合，6/10 局在对手某一回合净掉至少 4 血。

本方回合起点对手仍有至少 1 PP，且该轮既打旗又攻击的窗口共有 1 次，其中 0 次先攻后旗。示例 m0282 T6 输入 23 打旗，输入 28 攻击。

选芭芭萝丝回费的 6 回合里，2 回合把买炮手排在下一旗之前。示例 m0282 T10 输入 62 回费，输入 63 买炮手。

从行动记录能确认本方拆掉炮手或芭芭萝丝 10 次。敌回合用精炼命中这两种发动机共 0 次。
