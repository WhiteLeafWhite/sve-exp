# BP20 十主轴对困难财宝皇

在 2026-11-24 查询 SVE Helper Win 的「查看卡组」，按环境 `BP20` 和类型 `Basic` 筛选，返回 232 份牌表。选入的十套覆盖六职业，各自有不同的资源或赢牌主轴。每套的原始主战者、主牌和进化牌张数可在该套的 `source.json` 核对。少数牌表的主牌为 41 张或进化牌为 9 张，照原表进入对局。[网站卡组列表](https://www.svehelperwin.com/#/deck-list) · [BP20 时期的商品列表](https://shadowverse-evolve.com/cardlist/) · [选入的十套牌表](protocol.json)

我方自动执牌依据己方可见信息和对隐藏牌序的抽样。每套有各自的起手辅助、引擎估值和攻防取舍，40 局固定打法版本。财宝皇使用 `t7B32v` 原表，保留三张篡夺绝杰 BP05-018。沿用 SVE NEXT 标准构筑检查和原表陪练约定，关闭赛事禁限表。对手在所有对局使用同一困难预设 `hard-next`，强度 1，该预设按引擎设定可用隐藏信息。[财宝皇原表](../16-bp20-loot-300/decks/t7B32v.json) · [自动打法](pilot.mjs) · [引擎版本与牌表校验值](protocol.json)
